## La pile, le tas (intro)

- La pile (stack): on stocke les variables locales (int etc., types primitifs) et addresses de variables (tableaux, str, types référence) d'un programme de manière ordonnée. Chaque élément de la pile est de taille limitée.

- Le tas (head): le reste, pour les données prenant plus de taille, stockées "en vrac".

## Les types

Types primitifs:

- int, float, double, char, boolean, byte, short, long.
- Leur valeur par défaut est 0 (ou 0.0, false, '\u0000' selon le type).
- Ils sont stockés dans la pile.

Types référence:

- String, tableaux, classes définies par l'utilisateur.
- Leur valeur par défaut est null.
- Ils sont stockés dans le tas et la pile contient l'adresse de l'objet.

- Wrappers ou Type enveloppe: chaque type primitif possède un type référence associé:

| Type primitif | Type référence |
| ------------- | -------------- |
| int           | Integer        |
| float         | Float          |
| double        | Double         |
| char          | Character      |
| boolean       | Boolean        |
| byte          | Byte           |
| short         | Short          |
| long          | Long           |

# La pile

- Structure de données de type LIFO (Last In First Out).
- Trois opérations:
  - p.empty(): vérifie si la pile est vide.
  - p.push(x): ajoute l'élément x au sommet de la pile.
  - p.pop(): retire et retourne l'élément au sommet de la pile.

En java:

```java
import java.util.Stack;

Stack<Integer> stack = new Stack<>(); // PAS int !! mais le type référence
stack.push(10);
int v = stack.pop();
System.out.println(v); // affiche 10
```

**Différences entre tableaux et piles ?**

| Pile                                                              | Tableau                                           |
| ----------------------------------------------------------------- | ------------------------------------------------- |
| Ne peut stocker que des types références (ex: Integer)            | Peut stocker n'importe quel type de données       |
| Taille variable, illimitée                                        | Taille finie, fixée au départ                     |
| Ne peut ajouter ajouter ou retirer des éléments que sur le dessus | Peut accéder à tous les éléments sans restriction |

**Exemple: affichage binaire**
```java
import java.util.Stack;

public class Binaire {
    public static void main(String[] args) {
        Stack<Integer> stack = new Stack<>();
        int n = 147; 

        while (n > 0) {
            stack.push(n % 2); // 1ere itération: donne la parité, etc
            n = n / 2;
        }

        while (!stack.empty()) {
            System.out.print(stack.pop()); // Bon ordre
        }
    }
}
```

## Notation polonaise et polonaise inversée
- **x + y**: forme **infixe**
- **\+ x y**: forme **préfixe** (notation polonaise)
- **x y +**: forme **postfixe** (notation polonaise inversée)


## Arbre syntaxique
Exemple avec `(3 + 2) * (7 - (2 + 2))`
```
        *
       / \
      +   -
     / \ / \
    3  2 7  +
           / \
          2   2
```

- Forme infixe: `(3 + 2) * (7 - (2 + 2))`
- Forme préfixe: `* + 3 2 - 7 + 2 2`
Pour obtenir cette forme, on fait le "contour de l'arbre" en partant de la racine et dans le sens trigo. On note le symboles/nombres dans l'ordre de rencontre.
- Forme postfixe: `3 2 + 7 2 2 + - *`
Pour obtenir cette forme, on fait le contour mais on note seulement un symbole/nombre lorsque l'on arrive à sa droite.
