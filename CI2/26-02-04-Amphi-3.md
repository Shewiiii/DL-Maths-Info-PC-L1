# Paramètres de types et objets

En java, on utlise exclusivement l'**appel par valeur**, c'est à dire qu'on donne une copie de la valeur de la variable en paramètre à la méthode appelée.

Attention: on copie la valeur (int, ...) ou l'adresse (tableaux, ...) de la variable, pas la variable elle-même: une fonction qui modifie un tableau en argument modifie bien le tableau d'origine.

**Exemples:**

```java
public static void incrementer(int n) {
    n = n + 1;
}

public static void main(String[] args) {
    int a = 5;
    incrementer(a);
    System.out.println(a); // Affiche 5
}
```

```java
public static void modifierTableau(int[] t) {
    int[] u = { 5, 6, 7 };
    t = u;
    System.out.println("Pendant l'appel: " + t); // Adresse différente A2 !
}

public static void main(String[] args) {
    int[] t = {1, 2, 3};
    System.out.println("Avant l'appel: " + t); // Adresse initiale A1
    modifierTableau(t);
    System.out.println("Après l'appel: " + t); // Adresse initiale A1
    // Valeur finale : [1, 2, 3]
}
```

```java
public static void modify(int[] t) {
    for (int i = 0; i < t.length; i++) {
        t[i] *= 2;
    }
}

public static void main(String[] args) {
    int[] t = {1, 2, 3, 4, 5};
    System.out.println("Adresse de t : " + t);
    System.out.println("Contenu de t : " + Arrays.toString(t));
    modify(t);
    System.out.println("Adresse de t après modify : " + t);
    System.out.println("Contenu de t après modify : " + Arrays.toString(t));
    // Adresse: Inchangée
    // Valeur finale: [2, 4, 6, 8, 10]
}
```

```java
public class Chat {
    String nom;
    int age;

    public Chat(String nom, int age) {
        this.nom = nom;
        this.age = age;
    }

    public boolean vieillir() {
        this.age = this.age + 1;
        if (this.age > 12 && Math.random() < 0.025 * this.age) {
            System.out.println(this.nom + " est mort(e) à l'âge de " + this.age + " ans. RIP ts pmo tough for bro");
            return false;
        }
        System.out.println(this.nom + " a maintenant " + this.age
                + " et n'est pas mort. World is healing + ts so tuff gng icl");
        return true;
    }

    public static void main(String[] args) {
        Chat neko = new Chat("Turbo Granny", 0);
        while(neko.vieillir()) {}
    }

}
```

Pour afficher proprement la classe chat lorsque l'on `system.out.println(neko);`, on peut redéfinir dans la classe la méthode `toString()` (un peu comme `__repr__` en Python):

```java
@Override
public String toString() {
    return "Chat{nom='" + nom + "', age=" + age + "}";
}
```

## Intruction x++ et ++x

**x++**:
- Incrémente la variable x...
- ...Et renvoie l'**ancienne** valeur de x !


**++x**:
- Incrémente la variable x
- Renvoie la **nouvelle** valeur de x

```java
public static void main(String[] args) {
    int x = 0;
    int y = x++; 
    int z = ++x;
    System.out.println("x: " + x + ", y: " + y + ", z: " + z);
    // y = 0, z = x = 2
}
```
