### Partie 2: Traduction de programmes (Introduction)

## Qu'est ce qu'un ordinateur?

C'est une machine à calculer universelle (=tout ce qui est "calculable"), à condition d'avoir assez d'énergie et de mémoire et de temps.

**Principaux composants d'un ordinateur:**

- **Processeur** (CPU): exécute les instructions d'un programme.
- **Mémoire**: stocke les données et les programmes en cours d'exécution.
- **Périphériques d'entrée/sortie**: permettent de communiquer avec l'extérieur (clavier, écran, disque dur, etc.).

Le CPU peut seulement faire des **instructions très simples**:

- Faire une opération arithmétique (addition de 2 nombres)
- Lire ou écrire dans _une_ case mémoire
- Sauter à une autre instruction précise (jump)

Mais ne connaît pas:

- Les variables, boucles, fonctions etc.

Il faut donc traduire les programmes: c'est le rôle du **compilateur** (ex: javac) ou de l'**interpréteur** (ex: java).
En utilisant javac, on compile le code source Java en bytecode (fichier .class), qui est ensuite exécuté par la machine virtuelle Java (JVM).

## Décodage d'instructions machine

Chaque instruction que le processeur peut exécuter est encodée comme un mot binaure, en général stocké sur 32 ou 64 bits.

Exemple: `10110000 01100001 01100001 01100001`

L'instruction est composée de plusieurs blocs:

- **Opcode**: indique l'opération à effectuer (ex: addition, lecture mémoire, etc.)
- **Opérandes**: les données sur lesquelles l'opération doit être effectuée (ex: les adresses mémoire, les registres, etc.)

Le **jeu d'instructions** est l'ensemble des opérations possible sur une machine. C'est le constructeur qui le choisit, parmis plusieurs jeux d'instructions possibles (ex: x86, ARM, etc.).

Désavantage du langage machine: pas lisible du tout. Le **langage assembleur** permet donc de représenter les instructions machine de manière plus lisible, en utilisant des mots (ex: `ADD`, `MOV`, etc.) correspondant à un opcode précis.

## Pseudo assembleur: Pourquoi?

**CI2: PAS un cours de langage assembleur** !  
Langage inventé pour comprendre les concepts, sans rentrer dans les détails techniques.

Etablissons la machine fictive qui va exécuter le langage:

- Le CPU dispose de 8 registres (`R0` à `R7`) pour stocker des données temporairement (donc PAS dans la RAM)
- Il peut lire et écrire 10 à 100 fois plus vite dans les registres que dans la RAM
- Il dispose d'une variable `PC` indiquant l'index de l'instruction en cours d'exécution (Program Counter)

La syntaxe ressemblera à:

```
0: <instruction>
1: <instruction>
2: <instruction>
...
n: halt
```

## Instructions

> **move** \<registre>, \<valeur>
>
> Met une valeur (soit un registre, soit un entier) dans un registre (R0 à R7).

> **add** \<registre>, \<valeur1>, \<valeur2>
>
> Effectue l'addition de deux valeurs et le stocke dans un registre.  
> Même chose pour **sub**, **mul**, **div** et **mod**

Exemple:

```
0: move R0, 100        // met 100 à R0
1: move R1, 7          // met 7 à R1
2: div R2, R0, R1      // divise 100 par 7 (=14), stocke le résultat dans R2
3: mul R3, R1, R2      // multiplie 7 par 14 (=98), stocke le résultat dans R3
4: sub R4, R0, R3      // soustrait 98 de 100, stocke le résultat dans R4
```

> **jump_eq** \<valeur 1> \<valeur 2>, \<numero de ligne>
>
> Saute à la ligne indiquée si les deux valeurs sont égales.  
> Même chose pour **jump_neq**, **jump_g**, **jump_l**, etc.

> **halt**
>
> Arrête l'exécution du programme.

> **print** (\<valeur>)
>
> Affiche la valeur à l'écran (pas vraiment de l'assembleur, mais plus simple comme ca)

Exemple:

```
0: move R0, 0
1: move R1, 1
2: add R0, R0, R1
3: add R1, R1, 1
4: jump_le R1, 12, 2
5: print ("Resultat = " + R0)
6: halt
```

Retourne 78

**Exemple: calculer la racine carrée entière d'un nombre:**
idée: on met au carré un compteur qui part de 0, et on s'arrête dès que le carré dépasse le nombre donné.

Exemple avec racine de 150.

```
0: move R0, 150
1: move R1, 0
2: add R1, R1, 1 // Incrémente le compteur
3: mul R2, R1, R1
4: jump_le R2, R0, 2 // Valeur pas atteinte, on boucle
5: sub R1, R1, 1 // On a dépassé, on décrémente le compteur
6: print ("sqrt(150) = " + R1)
```

Retourne 12
