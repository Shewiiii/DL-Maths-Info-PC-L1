# Traduction de Java vers pseudo-assembleur

On va faire à la main le bouleau d'un **compilateur**.

On va procéder en deux étapes:

- Annoter le code Java, en indiquand:
  - quel registre assigner à chaque nom de variable.
  - Quels numéros de ligne d'assembleur correspondant à chaque ligne de Java.
- Traduire en pseudo-assembleur en s'aidant des annotations.
  - On va appliquer des règles précises pour chaque construction Java du programme Java.

**Exemple:**

```java
public static void main(String[] args) {
    int x = 1;              // PC = 0: move
    int y = 7;              // PC = 1: move
    x = y + 3;              // PC = 2: add
    int z = 2 * y + x;      // PC = 3, 4: mult, add
    z++;                    // PC = 5: add
    System.out.println(z);  // PC = 6: print
}                           // PC = 7: halt
```

**Pseudo-assembleur:**

```
0: move R0, 1
1: move R1, 7
2: add R0, R1, 3
3: mul R2, 2, R1
4: add R2, R2, R0
5: add R2, R2, 1
6: print R2
7: halt
```

**Exemple:**

```java
int x = 12;    // PC = 0: move
if (x > 10) {  // PC = 1: jump_le
    x += 7;    // PC = 2: add
}
// ...
```

**Pseudo-assembleur:**

```
0: move R0, 12
1: jump_le R0, 10, 3
2: add R0, R0, 7
// ...
```

**Exemple:**

```java
int x = 1;             // PC = 0: move
if (x > 0) {           // PC = 1: jump_le
    x--;               // PC = 2: sub
                       // PC = 3: jump
} else {
    x++;               // PC = 4: add
}
System.out.println(x); // PC = 5
                       // PC = 6 : halt
```

### Voici les règles générales

> ```java
> if ( <condition> ) {  // a: Si condition fausse, sauter à la ligne c
>     <instructions>    // b: Traduire les instructions
> }                     // c: Traduire la suite du programme
>
> ```

> ```java
> if ( <condition> ) {  // a: Si condition fausse, sauter à la ligne d
>     <instructions1>   // b: Traduire <instructions1>
>                       // c: Sauter à la ligne e
> } else {
>     <instructions2>   // d: Traduire <instructions2>
> }                     // e: Traduire la suite du programme
> ```

> ```java
> do {
>     <instructions>       // a: Traduire <instructions>
> } while ( <condition> ); // b: Si condition vraie, sauter à la ligne a
> ```

> ```java
> while ( <condition> ) { // a: Si condition fausse, sauter à la ligne d
>     <instructions>      // b: Traduire <instructions>
>                         // c: Sauter à la ligne a
> }                       // d: Traduire la suite du programme
> ```

> ```java
> for ( <initialisation>;   // a: Traduire l’initialisation
>     <condition>;          // b: Si condition fausse, sauter ligne f
>     <incrémentation> ) {
>     <instructions>        // c: Traduire les instructions
>                           // d: Traduire l’incrémentation
>                           // e: Sauter ligne b
> }                         // f: Traduire la suite du programme
> ```

## Une subtilité en Java

L'évaluation du `&&` n'est pas symétrique !  
Comment retranscrire cela en pseudo-assembleur?

> ```java
> if ( <condition_A>       // a: Si condition A fausse, sauter ligne d
>     && <condition_B> ) { // b: Si condition B fausse, sauter ligne d
>     <instructions>       // c: Traduire les instructions
> }                        // d: Traduire la suite du programme
> ```

Pour le `||`

> ```java
> if ( <condition_A>        // a: Si condition A vraie, sauter ligne c
>     || <condition_B> ) {  // b: Si condition B fausse, sauter ligne d
>     <instructions>        // c: Traduire les instructions
> }                         // d: Traduire la suite du programme
> ```

## Traduction des tableaux: Lire et écrire dans la mémoire

> **malloc** \<destination>, \<taille>  
>
> Alloue un bloc mémoire de la taille demandée.  
> L'adresse de la 1ère case est stockée dans la destination.

Pour désigner d'autres cases, on pourra écrire
- `[R0]` pour accéder à la 1ère case du tableau pointé par R0
- `[R0+78]` pour accéder à la 79ème case du tableau pointé par R0
- `[R0+R1]` pour accéder à la case pointée par R0 plus l'offset dans R1
