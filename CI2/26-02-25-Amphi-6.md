# La pile: push et pop

Rappel: elle permet de stocker:

- les variables locales des fonctions
- le numéro de la ligne courant de chaque fonction en cours d'exécution.

Mais comment la **pile est stockée dans la RAM** (~grand tableau avec cases mémoire) ?

- En pseudo-assembleur, on va supposer que la pile se trouve aux adresses allant de **@0000 0001 à @0000 ffff**
- L'addresse **@0000 0000** est réservée pour représenter la valeur `null`
- On a un registre spécial **SP (Stack Pointer)** qui pointe vers le sommet de la pile, c'est à dire la prochaine case libre (équivalant de `top` dans `MyStack` en Java), qui vaut 1 au début quand la pile est vide (pointant vers @0000 0001).

## Syntaxe

> **push** \<valeur>  
> Ajoute une valeur sur la pile. Equivaut à:
>
> ```
> 0: move [SP], <valeur>
> 1: add SP, SP, 1
> ```

> **pop** (\<n>)  
> Retire la valeur (ou les n premières valeurs) du sommet de la pile. Equivaut à:
>
> ```
> 0: sub SP, SP, <n>
> ```

> **call** \<numéro de ligne>
> Appel de fonction: empile le PC courant et saute à la ligne indiquée
>
> ```
> 0: push PC
> 1: jump <numéro de ligne>
> ```

> **ret**  
> Retour de fonction: dépile une valeur et la stocke dans le registre PC.
>
> ```
> 0: pop
> 1: move PC, [SP]
> ```

```java
public static void g() {
    System.out.println("Fonction g");  // 200: println
}                                      // 201: ret

public static void f() {
    System.out.println("Debut f");     // 100: println
    g();                               // 101: call 200
    System.out.println("Milieu f");    // 102: println
    g();                               // 103: call 200
    System.out.println("Fin f");       // 104: println
}                                      // 105: ret

public static void main(String[] args) {
    System.out.println("Debut main");  // 0: println
    f();                               // 1: call 100
    System.out.println("Fin main");    // 2: println
}                                      // 3: halt
```

Equivaut à:

```
0: println ("Debut main")
1: call 100
2: println ("Fin main")
3: halt
100: println ("Debut f")
101: call 200
102: println ("Milieu f")
103: call 200
104: println ("Fin f")
105: ret
200: println ("Fonction g")
201: ret
```

### Et les variables ?

Traduction d’un appel de fonction
Si on veut appeler la fonction f ayant pour prototype :

```java
public static void f (int arg1, int arg2, int arg3)
```

Règle générale :

```
f(expr1, expr2, expr3);
// a: Empiler les arguments de gauche à droite
// b: call <ligne_où_commence_f>
// ** c: Dépiler les arguments de f**
```

Il faut **évaluer** chacune des expressions données en argument à la fonction f
avant de pouvoir les empiler : ça peut prendre plusieurs instructions.

```java
// Variables de f :
// arg1 dans [SP-6], arg2 dans [SP-5], arg3 dans [SP-4],
// var1 dans [SP-2], var2 dans [SP-1]
public static void f (int arg1, int arg2, int arg3) {
    int var1 = ... ;       // a: push
    int var2 = ... ;       // b: push
    <corps_de_la_fonction> // c: Traduire le corps de la fonction f
}                          // d: Dépiler les variables locales de f
                           // e: ret
```

**Exemple**:

```java
// Variables de f : x dans [SP-1], a dans [SP-3]
public static void f(int a) {
    int x = 7;      // 100: push 7
    x = x + a;      // 101: add
    System.out.println("Dans f, x = " + x);    // 102: println
}                                              // 103, 104: pop, ret

// Variables du main : x dans [SP-2], y dans [SP-1]
public static void main(String[] args) {
    int x = 1;      // 0: push 1
    int y = 3;      // 1: push 3
    f(42);          // 2: push 42
                    // 3: call 100
                    // 4: pop
    System.out.println("Dans main, x = " + x); // 5: println
}                                              // 6,7: pop 2, hal
```

Equivaut à:

```
// Code du main :
0: push 1           // Variable x stockée sur la pile
1: push 3           // Variable y stockée sur la pile
2: push 42          // Argument de f
3: call 100         // Appel à f
4: pop              // On dépile l’argument de f
5: println ("Dans main, x = " + [SP-2])
6: pop 2            // On pop les variables locales, x et y
7: halt

// Code de f :
100: push 7         // Variable x stockée sur la pile
101: add [SP-1], [SP-1], [SP-3] // x = x + a
102: println ("Dans f, x = " + [SP-1])
103: pop            // On pop la variable x
104: ret
```
