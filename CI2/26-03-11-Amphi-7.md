# Traduire des objets

**Dans le tas**, on a une case mémoire pour chaque attribut.  
**Dans la pile**, on a l'adresse de où se trouve l'objet.

___

Essentiellement, un constructeur, c'est une fonction qui:

- Alloue la mémoire nécessaire pour représenter l'objet
- Initialise ces attributs
- Retourne l'adresse de l'objet créé

Exemple:

```java
public class Point {
    int x;
    int y;

    public Point(int x, int y) {
        this.x = x;
        this.y = y;
    }

    public static void afficher (Point p) {
        System.out.println("x = " + p.x + ", y = " + p.y);
    }
}
```


Equivaut à:

```
// Constructeur
100: malloc R0, 2
101: move [R0], [SP-3]
102: move [R0+1], [SP-2]
103: ret

// afficher
200: move R0, [SP-2]
201: println ("x = " + [R0] + ", y = " + [R0+1])
202: ret

// main "Point x = new Point(4, 7)"
0: push 4
1: push 7
2: call 100
3: pop 2
4: push R0
5: push [SP-1]
6: call 200
7: pop 2
8: halt
```
