# Récursivité

## Principe

Une définition récursive est une définition dans laquelle on fait référence à l'objet que l'on est en train de définir.

Une définition récursive doit terminer !
Pour s'en assurer, on suit le schéma suivant:

- Cas de base:
  - On donne une ou plusieurs variables initiales
  - Le bas de base ne doit pas être récursif
- Cas récursif:
  - On suppose que la fonction a été définie pour des valeurs plus petites.
  - On exprime la valeur de la fonction pour un argument donné, en termes de la valeur de la fonction pour les arguments plus petits.

Mais en assembleur, ça donne quoi ?

```java
public static int u(int n) {
    if (n == 0) {
        return 0;
    } else {
        return (2 * u(n-1) + 3);
    }
}

public static void main (String[] args) {
    System.out.println(u(5));
}
```

Equivaut à:

```
0: push 5   //
1: call 100 // Appel initial : u(5)
2: pop      //
3: println (R0) // Le résultat est dans R0 : on l’affiche.
4: halt
100: jump_neq [SP-2], 0, 103 // Le dernier R0 empilé
101: move R0, 0     // Cas de base : on renvoie 0
102: ret
103: sub R0, [SP-2], 1 // Cas récursif :
104: push R0           //
105: call 100          // u(n-1)
106: pop               // On dépile le dernier R0 (0)
107: mul R0, R0, 2     // * 2
108: add R0, R0, 3     // + 3
109: ret
```

Quand on écrit un programme récursif, il y a deux façons de réfléchir:
(A) On dérouole dans sa tête les appels récursifs.
(B) On fait une hypothèse de récurrence: lorsqu'on fait un appel récursif, on suppose que le programme renvoie le bon résultat.

(A): c'est ce qui se passe vraiment, mais demande trop de mémoire (et compliqué à faire à la main).
(B): Plus simple !

- Avant de commencer:
  - Quel est la spécification de la fonction ?
- Cas de base:
  - Pour quelles valeurs d'entrée peut-on répondre immédiatement au prblème ?
- Cas récursif:
  - Sur quelles valeurs a-t-on droit de faire un appel récursif
  - Que nous garentit la spécification à propos du résultat de l'appel récursif ?
  - En **supposant** que le résultat de l'appel récursif satisfait la spécification, que nous reste-t-il à faire pour résoudre le problème ?

**Exemple**: paquet de cartes avec boîte magique à appel récursif.

- Spécification: Entrée: paquet, Sortie: paquet trié
- Cas de base: un paquet de 0 ou 1 carte est déjà trié
- Cas récursif:
  - On peut faire un appel récursif sur un paquet de n-1 cartes
  - En supposant que le résultat de cet appel récursif est un paquet trié (la boîte magique l'a fait pour nous !), il nous reste à insérer la carte restante à la bonne place dans le paquet trié.

```java
public static LinkedList<Integer> trier (LinkedList<Integer> list) {
    if (list.size() <= 1) {
        return list;
    }
    int tete = list.removeFirst();
    list = trier(list);
    return inserer(tete, list);
}
```

$\rightarrow$ Il reste à coder la fonction insérer, de manière récursive par exemple:

- Spécification: Entrée: paquet et carte, Sortie: paquet avec la carte insérée à la bonne place
- Cas de base: un paquet de 0 cartes, ou la première carte est plus grande que la carte à insérer: on l'insère en première position
- Cas récursif:
  - On retire la première carte du paquet.
  - On insère la suite (appel récursif).
  - On remet la première carte au dessus du paquet.

```java
public static LinkedList<Integer> inserer (int x, LinkedList<Integer> list) {
    if (list.isEmpty() || x <= list.getFirst()) {
        list.addFirst(x);
        return list;
    }
    int y = list.removeFirst();
    list = inserer(x, list);
    list.addFirst(y);
    return list;
}
```

**Autre exemple**: Créer une fonction `evaluate` qui évalue des expressions arithmétiques du type `(36-12)*(10-4)` avec en sortie le résultat de l'expression.

- Cas de base: Si `expr` ne contient que des chiffres: `Integer.valueOf(expr)`
- Cas récursif:
  - Si expr est de la forme : expr = expr1 ’+’ expr2.  
    Les chaînes expr1 et expr2 sont plus petites que expr.  
    J’ai le droit de faire les appels récursifs evaluate(expr1) et evaluate(expr2).
    Ça me donne la valeur des deux sous-expressions !
    Il reste juste à calculer valeur1 + valeur2.
  - Pareil pour ’-’, ’\*’ et ’/’.
  - Si expr est de la forme : expr = ’(’ expr1 ’)’.  
    La chaîne de caractères expr1 est plus petite que expr.  
    On a le droit de faire un appel récursif evaluate(expr1).  
    Ça me donne directement le résultat !

Variant d'appel: Longueur de String `expr`.
