## Récursivité terminale

Un bon mémotechnique: une fonction est récursive terminale si le **le return est un appel récursif**.

Exemple avec la fonction somme:
https://www.irif.fr/~ledent/teaching/ci2/

```
// Fonction main
0: push 50000   //
1: call 100     // Appel somme(50000)
2: pop          //
3: println R0   // Affichage du résultat
4: halt
// Fonction somme(n)
100: push [SP-2] //
101: push 0      //
102: call 200 // Appel somme(n, 0)
103: pop 2      //
104: ret

// Fonction somme(n, acc)
200: jump_neq [SP-3], 0, 203    // If (n == 0)
201: move R0, [SP-2]            // Cas de base: return acc
202: ret
203: sub R0, [SP-3], 1          // Calcul de n-1
204: add R1, [SP-2], [SP-3]     // Calcul de acc+n
205: pop 3
206: push R0                    //
207: push R1                    //
208: call 200                   // Appel somme(n-1, acc+n)
209: pop 2                      //
210: ret                        // Résultat déjà dans R0
```

La ligne 205 permet de dépiler les arguments de la fonction somme(n, acc) avant d'appeler la fonction somme(n-1, acc+n).

## Une erreur commune

```java
public static int f(int n) {
    if (n == 0) {
        return 0;
    }
    if (f(n-1) % 2 == 0) {
        return f(n-1) + n;
    } else {
        return f(n-1) - n;
    }
}
```

Il est important de poser une variable pour poser le résultat de l'appel récursif pour ne pas faire de calcul inutiles:

- Avec 2 f(n-1), complexité en O(2^n)
- Avec une variable temporaire, complexité en O(n)

Correction:

```java
public static int f(int n) {
    if (n == 0) {
        return 0;
    }
    int temp = f(n-1);
    if (temp % 2 == 0) {
        return temp + n;
    } else {
        return temp - n;
    }
}
```

---

**Exemple**: Fibonacci récursive terminale (ma version):

```java
public class Fibo {
    public static long fiboAux(int i, int n, long u1, long u2) {
        if (n == 0)
            return 0;
        if (i == n) {
            return u1;
        }
        return fiboAux(i + 1, n, u2, u1 + u2);
    }

    public static long fibo(int n) {
        return fiboAux(0, n, 0, 1);
    }

    public static void main(String[] args) {
        System.out.println(fibo(50));
    }
}
```
