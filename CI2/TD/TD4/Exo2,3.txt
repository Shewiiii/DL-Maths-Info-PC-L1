# Exo 2
0: move R0, 3 // Carré à calculer (+compteur décroissant)
1: move R1, 0 // Résultat
2: jump_le R0, 0, 8
3: move R2, R0 // Copie valeur pour le mettre au carré,puis l'ajouter à R1
4: mul R2, R2, R2
5: add R1, R1, R2
6: sub R0, R0, 1
7: jump 2
8: print("Résultat = " + R1)
9: halt
