## Rappels

```java
public class Fruit {
    String nom;
    int poids;

    Fruit(String nom, int poids) { // Constructeur
    nom = nom;
    poids = poids;
    }
}
```

Un constructeur est une sorte de méthode:

- qui n'est pas statique,
- qui n'a pas besoin de type de retour (même pas void)
- qui porte le même nom que la classe.
  Il est appelé automatiquement lors de la création d'un objet avec `new`.

# Static or not Static ?

Quatre notations:

```java
MaClasse.maMethode()
```

- Accès à la méthode `maMethode`
- Ecrite statique dans la classe `MaClasse`

```java
monObjet.monContenu
```

- Accès à la méthode `maMethode`
- Ecrite non statique dans la classe de l'objet `monContenu`

```java
MaClasse.sonPropreContenu
```

- Accès au champ unique `sonPropreContenu`
- Ecrite statique dans la classe `MaClasse`
- Partagée par toutes les instances de la classe

```java
monObjet.maPropreMethode()
```

- Accès à la méthode `maPropreMethode`
- Non statique dans la classe de l'objet `monObjet` (utilise des variables d'instance)

**Données de classe vs Données d'instance**:

```java
public class Example{
    static int nbInstances = 0; // variable de classe,
                                // partagée par toutes les instances

    String info;                // vari*able d'instance,
                                // propre à chaque instance
    Example(String info){
        info = info;
        nbInstances++;
    }
}
```

```java
public class Test{
    public static void main(String[] args){
        Example ex1 = new Example("Premier");
        Example ex2 = new Example("Deuxième");
        System.out.println(Example.nbInstances); // affiche 2
    }
}
```

Les variables de classe (`static`) sont partagées par toutes les instances de la classe.

**Exemple de méthode non statique** de la méthode `distance`:

```java
public class Point {
    int x, y;
    Point(int x, int y){
        x = x;
        y = y;
    }
    public double distance(Point autre){ // pas de mot clé "static"
        int dx = x - autre.x;
        int dy = y - autre.y;
        return Math.sqrt(dx*dx + dy*dy);
    }
}
```

```java
public class Test {
    public static void main(String[] args){
        Point toi = new Point(0, 0);
        Point lui = new Point(3, 4);
        System.out.println(toi.distance(lui)); //
    }
}
```

**Une alternative statique** à `distance`:

```java
//...
public static double distance(Point p1, Point p2){
    int dx = p1.x - p2.x;
    int dy = p1.y - p2.y;
    return Math.sqrt(dx*dx + dy*dy);
}
```

**Pourquoi utiliser `static` dans la méthode main ?**  
Car java appelle la méthode `main` sans créer d'instance de la classe, mais de l'exétieur.

# Le mot clé `this`

```java
// ...
public static double distance(Point a, Point b){
    int dx = a.x - b.x;
    int dy = a.y - b.y;
    return Math.sqrt(dx*dx + dy*dy);
}
public double distance(Point autre) {
    return Point.distance(this, autre); //
}
```

```java
public class Test {
    public static void main(String[] args){
        Point a = new Point(0, 0);
        Point b = new Point(3, 4);
        System.out.println(a.distance(b)); // "this est remplacé par a"
    }
}
```

- `this` permet de réduire l'ambiguïté, même si parfois pas obligatoire:

```java
//...
public double distance(Point autre) {
    int dx = this.x - autre.x;
    int dy = this.y - autre.y;
    return Math.sqrt(dx*dx + dy*dy);
}
```

- `this` sert aussi à réutiliser un constructeur précédemment écrit
- Possible seulement en première instruction

```java
public class Cercle {
    Point centre;
    double rayon;

    Cercle(Point centre, double rayon){
        this.centre = centre;
        this.rayon = rayon;
    }

    Cercle(double rayon){
        this(new Point(0, 0), rayon); // réutilisation du constructeur précédent
    }
}
```

# La vie privée des objets

- `public`: champs et méthodes accessibles de partout
- `private`: champs et méthodes accessibles seulement dans la classe
- ## `final`: champ constant, non modifiable après initialisation
- Méthodes getters et setters: méthodes permettant de lire et de modifier des champs privés
- Conviention de l'ordre des définitions dans une classe:
  1. Champs
  2. Constructeurs
  3. Getters et setters
  4. Méthodes plus complexes

**Exemple** en modélisant un gueux:

```java
public class Gueux {
    static int anneeCourante = 2030; // Connaissance partagée
    final String nom; // Son nom change pas
    final int anneeNaissance; // Son année de naissance non plus

    Gueux(String nom) {
        this.nom = nom;
        this.anneeNaissance = anneeCourante;
    }
}
```

**Problème**: on peut time travel

```java
Gueux.anneeCourante +=  100;
```

**Solution**: rendre anneeCourante privée et ajouter un setter

```java
public class Gueux {
    static private int anneeCourante = 2030;
    //...

    public static void anneeSuivante() {
        anneeCourante++;
    }
}
```

**Exemple**: cacher l'age d'un gueux pour les mineurs

```java
public class Gueux {
    //...
    private final int anneeNaissance;
    public int getAge() { // getter
        int age = anneeCourante - anneeNaissance;
        if (age < 18) {
            return -1; // âge caché
        } else {
            return age;
        }
    }
}
```

## Notion de contrat / interface
On définit ce qu'une classe offre comme services (méthodes publiques) sans révéler son fonctionnement interne (champs privés, méthodes privées).
On indique les en-têtes des méthodes.

```java
public interface Vehicule {
    public boolean demarre( int code);
    public void stop();
    public int accelere();
    // etc
}
```
```java
public class Automobile implements Vehicule {
    private String modele;
    private int codeCle;
    private boolean estEnMarche;
    private boolean demarre(int code) {
        if (code == this.codeCle) {
            estEnMarche = true;
        }
        return estEnMarche;
    }
    // et toutes les autres méthodes de l'interface véhicule
}
```

- L'utilisateur connait les méthodes qu'il peut utiliser, sans à se soucier de l'implémentation.
- On retrouve cela par exemple dans l'API de la classe `String`:
```java
String(char[] value);
char charAt(int index);
boolean equals(Object anObject);
boolean endsWith(String suffix);
static String valueOf(int i);
```
Exemple d'utilisation:
```java
public class TestString {
    public static void main(String[] args) {
        public static void main(String[] args) {
            char[] t = {'a', 'b', 'c'};
            String s = new String(t);
            System.out.println("Le second caractère est " + s.charAt(1));
            System.out.println(s.endsWith("bc"));
            String cent = String.valueOf(100);
            System.out.println("cent" + 0); // Concatène !
        }
    }
}
```
