```ocaml
let c f g = fun x -> g (f x) in fun h -> c h ((+) 1)
```

- Type de c: `('c -> 'e) -> ('e -> 'f) -> 'c -> 'f`  , 'c étant le type de x.
- Mais à cause de la contrainte `fun h -> c h ((+) 1)`, on a en fait 
`'h -> (int -> int) -> 'k -> int` avec 'h le type de h est 'k un type quelconque.

```ocaml
let rec fold_right f xs acc =
  match xs with
  | [] -> acc
  | x :: xs -> f x (fold_right f xs acc)
```

- Type: `('a -> 'b -> 'b) -> 'a list -> 'b -> 'b`

```ocaml
let transform f xs = 
    fold_right 
        (fun x ys -> match f x with None -> ys | Some y -> y :: ys)
        xs
        []
```

- Type: `(a -> 'b option) -> 'a list -> 'b list`

## Retour sur les listes
```ocaml
type 'a list = 
| [] 
| (::) of 'a * 'a list
```

**Exemple**:
```ocaml
let xs = (::) ('a', (::) ('b', (::) ('c', [])))
let xs' = 'a :: 'b :: 'c :: []
let xs'' = ['a'; 'b'; 'c']
```
